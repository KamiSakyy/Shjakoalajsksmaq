# Asuna Studio ✳

Бот ищет существующие арты Асуны и Кирито через публичные API Danbooru, Safebooru и Konachan (с резервными источниками) и обновляет одну публикацию в Telegram-канале примерно каждые 10 секунд. Картинки не генерируются. В подписи поста только «Бесконечные арты САО каждые 10 секунд».

В проекте есть Dockerfile, Docker Compose и Procfile для хостингов с автозапуском Python. Переменные окружения и пароли не требуются. Хостинг должен поддерживать постоянно работающий процесс и исходящие HTTPS-запросы к Telegram и Danbooru. Для сохранения настроек после перезапуска на Railway нужен Volume (например, с путём `/data`); приложение определит его автоматически. Без Volume настройки могут пропасть при перезапуске или новом развёртывании. Статический и serverless-хостинг не подходят. Docker Compose использует постоянный volume автоматически.

В панели введите токен от BotFather и добавьте бота администратором канала с правами публикации и редактирования. Если бот уже был добавлен, Telegram не позволяет получить список таких каналов: добавьте его заново или перешлите боту пост из канала. При подключении отключается существующий webhook бота. Используйте только один экземпляр приложения на один токен.

Панель намеренно работает без пароля: любой, кто может её открыть, сможет управлять ботом или подменить токен. Не публикуйте её в открытом интернете без внешней защиты доступа и HTTPS. Токен хранится на сервере.

Внешние сервисы и интернет могут ограничивать скорость или быть недоступными, поэтому интервал не гарантирован. Количество артов в интернете не бесконечно, они могут повторяться. При удалении поста вручную бот не создаст новый автоматически. Учитывайте права авторов изображений.

На сайте доступен журнал поиска, загрузки и публикации с сообщениями об ошибках. Внешние API могут ограничивать запросы или быть недоступны; при ошибках бот ждёт перед повтором.

В панели можно выбрать Асуну, Кирито, их совместные арты или все варианты вперемешку. Пауза сохраняет ID поста и при продолжении меняет то же сообщение. Выбранный канал и ID поста видны в панели; ID существующего поста можно указать вручную.

Кнопка экспорта сохраняет в TXT токен бота, выбранный канал, ID постов и категорию. Импорт проверяет токен и права бота, восстанавливает данные и оставляет работу на паузе. Telegram не позволяет заранее проверить, существует ли сохранённый пост и может ли бот его редактировать; при ошибке новый пост не создаётся. При первом экспорте для ранее подключённого бота может потребоваться один раз ввести токен в поле панели. После подключения или импорта токен запоминается в локальном хранилище браузера для экспорта.

**Берегите TXT и устройство:** файл и локальное хранилище браузера содержат токен. Любой, кто получит токен, сможет управлять ботом. Не отправляйте файл другим людям. Доступ к панели без пароля по-прежнему позволяет посторонним управлять настройками, хотя экспорт требует токен.

Канал можно указать вручную по ID, @имени или ссылке на канал. Ссылка на пост (например, `https://t.me/AsunaYukki/879`) также устанавливает ID сообщения, которое бот попробует редактировать. Бот должен быть администратором канала; выбор переводит его на паузу. Telegram не позволяет заранее проверить, принадлежит ли пост боту: проверка происходит при редактировании.

Перед публикацией бот проверяет теги SAO, выбранных персонажей и безопасный рейтинг. Из выдачи исключаются отмеченные кроссоверы, посторонние персонажи, группы, изображения с пометкой AI и откровенные изображения. Проверка зависит от тегов сайтов и не гарантирует точное распознавание содержимого. Причины отсева видны в журнале.
