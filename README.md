# Asuna Studio ✳

Бот ищет существующие арты Асуны Юки через публичный API Danbooru и обновляет одну публикацию в Telegram-канале примерно каждые 10 секунд. Картинки не генерируются; ссылка на источник указывается в подписи.

В проекте есть Dockerfile, Docker Compose и Procfile для хостингов с автозапуском Python. Переменные окружения и пароли не требуются. Хостинг должен поддерживать постоянно работающий процесс и исходящие HTTPS-запросы к Telegram и Danbooru. Для сохранения настроек после перезапуска на Railway нужен Volume (например, с путём `/data`); приложение определит его автоматически. Без Volume настройки могут пропасть при перезапуске или новом развёртывании. Статический и serverless-хостинг не подходят. Docker Compose использует постоянный volume автоматически.

В панели введите токен от BotFather и добавьте бота администратором канала с правами публикации и редактирования. Если бот уже был добавлен, Telegram не позволяет получить список таких каналов: добавьте его заново или перешлите боту пост из канала. При подключении отключается существующий webhook бота. Используйте только один экземпляр приложения на один токен.

Панель намеренно работает без пароля: любой, кто может её открыть, сможет управлять ботом или подменить токен. Не публикуйте её в открытом интернете без внешней защиты доступа и HTTPS. Токен хранится на сервере.

Внешние сервисы и интернет могут ограничивать скорость или быть недоступными, поэтому интервал не гарантирован. Количество артов в интернете не бесконечно, они могут повторяться. При удалении поста вручную бот не создаст новый автоматически. Учитывайте права авторов изображений.
