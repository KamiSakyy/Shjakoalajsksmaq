# перекинь

Сайт для обмена файлами: загрузка с телефона или компьютера и прямая ссылка на скачивание. Можно выбрать до 20 файлов, размер каждого — до 100 МБ. Один файл скачивается напрямую, несколько — одним ZIP-архивом по общей ссылке.

## Запуск

Требуется Node.js 18 или новее.

```sh
npm ci
npm start
```

Откройте http://localhost:3000. Порт задаётся переменной `PORT`, папка файлов — `DATA_DIR` (по умолчанию `uploads/`). Файлы сохраняются на сервере и доступны любому, у кого есть случайная ссылка. Не загружайте конфиденциальные данные.

## Публикация

Нужен хостинг с Node.js и постоянным диском: запустите `npm ci`, затем `npm start`, задайте `DATA_DIR` на постоянный диск. Без постоянного диска файлы могут пропасть при перезапуске. GitHub Pages поддерживает только статические сайты и не может сохранять загружаемые файлы; одна загрузка файлов в корень GitHub не создаёт работающий файловый хостинг. Для общедоступной ссылки необходим развёрнутый сервер с HTTPS и постоянным хранилищем.
