# ТОПОР.НОЧЬ · Майами

Браузерная 3D-песочница на three.js: ночной Майами-Бич с Ocean Drive, пляжем,
настоящим шейдером океана, квестами, телефоном, полицией, вертолётами и танками.
Можно лазать по стенам и крышам, перелезать через заборы, стрелять с настоящей
баллистикой, покупать машины, мотоциклы и оружие прямо в телефоне и выбирать
один из трёх режимов мира. Работает на ПК и на Android прямо в браузере.
**Собирается в один файл `index.html`.** Всего в игре **193 задокументированные системы**:
118 из обновления «Кровь и неон» и 75 из обновления «Прыжок и пуля».

Готовый файл — [`handoff/index.html`](handoff/index.html). Его можно открыть
двойным кликом (с телефона — тоже), положить на GitHub Pages или отправить другу
одним вложением: внутри уже лежат все скрипты, стили, текстуры, фото меню и шрифты.

## Как запустить

### Вариант 1 — просто открыть файл
Скачайте `handoff/index.html` и откройте в браузере (Chrome/Edge/Safari/Firefox).
Сборка полностью автономна: ни одного сетевого запроса, `file://` поддерживается.

### Вариант 2 — GitHub Pages через Actions
1. Загрузите репозиторий на GitHub (ветка `main`).
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Каждый пуш в `main` workflow `.github/workflows/deploy.yml` соберёт игру,
   проверит типы и шейдеры, выложит её на Pages и положит `index.html`
   в артефакт сборки (**Actions → сборка → Artifacts**).

### Вариант 3 — локальная разработка
```bash
npm ci
npm run dev        # http://localhost:5173
npm run build      # dist/index.html + handoff/index.html
npm run typecheck  # tsc --noEmit
npm run check:shaders
```

## Что внутри

### Мир
- **Майами-Бич**: Ocean Drive, 20+ отелей в стиле ар-деко с неоновыми вывесками,
  пляж с дюнами и пальмами, променад, дамба, марина с яхтами, остров Миллионеров,
  даунтаун со стеклянными башнями.
- **Океан** — отдельный шейдер: аналитическая линия берега (вода физически не может
  залить город), 6 волн Герстнера в вершинном шейдере, градиент по глубине,
  пена у кромки, отражение солнца и луны, блики, каустика и дымка на горизонте.
  На мобильных часть шума отключается автоматически.
- **Живой город**: пробки и светофоры, пешеходы, зомби, погода, дождь и лужи,
  день/ночь, аварии, пожарные и скорая.

### Игрок
- Топор, пистолет, дробовик, ближний бой, трясучка камеры, кровь и трассеры.
- **Ограбления**: наведите оружие на прохожего → «обыскать» → деньги, телефон
  или ничего. Растёт розыск.
- **Телефон** (`P` или `Tab`): задания, кошелёк (наличные/банк, вклады, история
  операций), карта, камера (снимки сохраняются), контакты, настройки качества.
- **Экономика**: наличные + банк, награды за задания, $500 за вертолёт,
  $1200 за танк, $150 за уничтоженную патрульную машину.

### Погоня
- 1–3 звезды — патрульные машины, 4 — **вертолёт**, 5 — **танк**.
- Патрульную машину можно **взорвать** и можно **угнать**, сев за руль.
- Вертолёт и танк сбиваются выстрелами, за них платят и дают опыт.

### Сюжет
8 глав: «Прилёт» → «Долги» → «Доставка» → «Горячий вечер» → «Открытка» →
«Шум сверху» → «Броня» → «Король города». После финала открываются побочные
заказы. Точка цели отмечается столбом света и кольцом, трекер — в HUD,
полный список — в телефоне.

## Оптимизация под Android

| Что | Как |
| --- | --- |
| Качество | `auto` / `low` / `high` / `ultra` — определяется по устройству, меняется в паузе и в телефоне |
| Разрешение | адаптивное: при просадке FPS рендер идёт в меньшем буфере и растягивается на экран |
| Тени | карта теней 512–2048, дальность и радиус по бюджету |
| Вода | сегментов сетки 48–128, ветки шума только на `ultra` |
| Свет | пул точечных источников (фары/фонари), лишние выключаются |
| Постобработка | bloom + ACES + грейд только на `high`/`ultra`, на мобильных — прямой рендер |
| Память | геометрия слита (`mergeGeometries`), материалы переиспользуются, текстуры кешируются |

## Структура

```
src/game/        движок: город, океан, Майами, полиция, воздух, квесты, экономика…
src/components/  интерфейс: HUD, телефон, карта, управление, меню
src/assets/      текстуры, фото меню и шрифты (вшиваются в сборку)
handoff/         готовый одиночный index.html
scripts/         копирование сборки в handoff, проверка GLSL
.github/         workflow сборки и публикации на GitHub Pages
```

Лицензии шрифтов — `public/fonts/*-OFL.txt`, атрибуции моделей и текстур —
`public/models/**`, `public/textures/ATTRIBUTION.txt`.
