# ТОПОР.НОЧЬ: Район Пасифик

Исходный сайт и нативный Gradle-проект Android находятся в репозитории. Android-версия запускает собранную игру из ресурсов APK в полноэкранном WebView, без сетевого разрешения и без подключения к серверу. Настройки и пункт назначения карты сохраняются между запусками. Подробная инструкция сборки APK находится в [`android/README.md`](android/README.md).

Для сборки сайта: `npm ci && npm run build`.
Для обновления локальных Android-ресурсов: `./android/sync-web-assets.sh`.
