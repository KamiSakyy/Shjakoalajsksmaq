# Игра в одном файле

`index.html` — вся игра целиком: код, стили, текстуры, фото меню и шрифты внутри.
Интернет не нужен, сервер не нужен.

- Открыть на ПК: двойной клик по файлу.
- Открыть на Android: скачать файл и открыть в Chrome (или «Добавить на главный экран»).
- Выложить в интернет: положите файл в корень репозитория и включите GitHub Pages
  (Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`).
  Либо используйте готовый workflow из `.github/workflows/deploy.yml`.

Управление: `WASD` — ходьба, мышь — обзор, `Shift` — бег, `Space` — прыжок и паркур
(держи у стены — полезешь на крышу; в машине — ручник), `X` — присед, перекат при
приземлении, скольжение на бегу, `F` — сесть в машину / обыскать / банкомат,
`G` — бросить бутылку с огнём, `T` — сменить снаряд, `P` — телефон (там же магазин:
машины, мотоциклы, оружие и тюнинг), `M` — карта, `Esc` — пауза.

Три режима: **Мирный** (только люди, полиция не гоняется, никто не сопротивляется),
**Обычный** (как в GTA) и **Зомби-апокалипсис** (прыгуны, кровососы, сталкеры и
группировки в духе «Зова Припяти»).
