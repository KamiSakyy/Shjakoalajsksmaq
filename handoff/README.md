# Игра в одном файле

`index.html` — вся игра целиком: код, стили, текстуры, фото меню и шрифты внутри.
Интернет не нужен, сервер не нужен.

- Открыть на ПК: двойной клик по файлу.
- Открыть на Android: скачать файл и открыть в Chrome (или «Добавить на главный экран»).
- Выложить в интернет: положите файл в корень репозитория и включите GitHub Pages
  (Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`).
  Либо используйте готовый workflow из `.github/workflows/deploy.yml`.

Управление: `WASD` — ходьба, мышь — обзор, `Shift` — бег, `Space` — прыжок и паркур
(держи у стены — полезешь на крышу; в машине — ручник), `X` — присед, перекат при
приземлении, скольжение на бегу, `F` — сесть в машину / обыскать / банкомат,
`G` — бросить бутылку с огнём, `T` — сменить снаряд, `P` — телефон (там же магазин:
машины, мотоциклы, оружие и тюнинг), `M` — карта, `Esc` — пауза.

Мир статичный: у него фиксированное зерно, поэтому город одинаков у всех и при
каждом запуске (подпись мира видна на стартовом экране). Это же делает возможным
онлайн: по сети передаётся только изменяемое состояние.

Три режима: **Мирный** (только люди, полиция не гоняется, никто не сопротивляется),
**Обычный** (как в GTA) и **Зомби-апокалипсис** (прыгуны, кровососы, сталкеры и
группировки в духе «Зова Припяти»).

## Кровь и топоры

В телефоне появилось приложение **«Топоры»** (иконка ⚒): десять инструментов,
все **бесплатно**, взять можно даже сидя в машине. У каждого своя длина, масса,
момент инерции и форма головы, поэтому они по-настоящему по-разному рубят:
топорик снимает кисти и стопы, палач сносит голову одним резом, бардиш с 1,4 м
перерубает торс, кувалда не режет, а ломает кости и вязнет в мясе. Разруб
считается в джоулях по прочности кости: шея ~90 Дж, кость руки ~120 Дж,
позвоночник ~320 Дж, плюс накопитель реза — слабым топором одно место рубят
несколько раз.

Кровь переделана: вместо трёхмерных шаров — плоские капли-струйки, развёрнутые
к камере и вытянутые по вектору скорости, плюс мягкий аэрозоль, артериальные
фонтаны импульсами и лужи. Небо тоже стало честнее: облака считаются в мировых
координатах, тень облака ползёт по улице, а когда туча закрывает солнце над
головой, гаснет именно солнце, и экспозиция подстраивается как зрачок.

Всё это сделано так, чтобы работало и на слабых телефонах: плоские капли вчетверо
дешевле шаров, тень облаков — один квад, число октав неба берётся из бюджета
устройства.
